# VetCare-IS
Информационная система учета пациентов и медицинских услуг ветеринарной клиники

## Концепция системы
Веб-приложение для ветеринарных врачей, администраторов и владельцев животных.
Позволяет вести электронные медицинские карты питомцев, записывать на прием,
учитывать оказанные услуги и формировать счета.

## Технологический стек
* **Фронтенд:** React, HTML5, CSS3, JavaScript
* **Бэкенд:** Node.js / Express
* **СУБД:** PostgreSQL / MySQL

## Структура папок проекта
/client      - клиентская часть (React, карточки пациентов, формы приема)
/server      - серверная часть, обработка REST API запросов
/database    - схемы базы данных и SQL-скрипты миграций
.env.example - пример конфигурационного файла окружения
.gitignore   - файл исключений для Git
